\section{1. Data Understanding}
\begin{itemize}[leftmargin=1.5em]
    \item \textit{What data are you investigating?} 
          Spatio-temporal data aggregated by the United Nations Office on Drugs and Crime (UNODC), detailing global drug prices, purity levels, and seizure volumes.
          
    \item \textit{What are your questions about the data?} 
          1) What is the correlation between the volume of law enforcement drug seizures and the subsequent street price and purity of those drugs in European markets? 
          2) Which European markets exhibit the highest profit margins (retail vs.\ wholesale price disparity)? 
          3) How do localized seizure events impact neighboring countries' drug markets?
          4) Which countries prove to be a more profitable market?
          5) Which drugs should law enforcement focus on in which countries?

    \item \textit{Why is this interesting / relevant?}
          Understanding the response of illicit markets in response to law enforcement busts is critical for policy-making. It helps authorities determine whether seizures effectively disrupt markets or inadvertently increase drug profitability and risk.
\end{itemize}

\section{2. Data Mining}
\begin{itemize}[leftmargin=1.5em]
    \item \textit{Where and how do you expect to find the necessary data?}
          Open-source datasets provided by the UNODC data portal (https://data.unodc.org).

    \item \textit{How will you retrieve the data?}
          Data will be systematically extracted via CSV/Excel exports.
\end{itemize}

\section{3. Data Cleaning}
\begin{itemize}[leftmargin=1.5em]
    \item \textit{Do you have to merge multiple data sets?}
          Yes. The raw data spans multiple sheets and files separated by metric. These will be normalized and joined into a centralized relational table.

    \item \textit{Do you expect to have missing or uncertain data values?}
          Yes. Reporting varies significantly by country and year, leading to potentially sparse and variable quality data.

    \item \textit{How will you handle those?}
          We will exclusively focus on drugs and countries which have sufficient data for rigorous analysis, and in the case of sporadic missing values, these will be imputed, while being flagged as originally missing.
\end{itemize}

\section{4. Data Exploration}
\begin{itemize}[leftmargin=1.5em]
    \item \textit{Which visual encoding and interaction techniques do you
          plan to use to explore the data and to derive hypotheses?}
          We will utilize choropleth maps to display geographic data. We shall implement linking: selecting a specific country will dynamically filter related plots (scatterplots, line charts, bar charts).

    \item \textit{Which programs / libraries / tools do you plan to use?}
          Python will form the backbone of the project. Libraries such as Pandas and Scikit Learn will be used for the main ETL processing, while the interactive frontend will be built using Streamlit.
\end{itemize}

\section{5. Feature Engineering}
\begin{itemize}[leftmargin=1.5em]
    \item \textit{Which data attributes / features do you plan to select
          or extract to answer your questions?}
          \begin{itemize}
              \item \textbf{Market Markup:} In-country price spreads (Retail Price - Wholesale Price).
              \item \textbf{Value-to-Risk Ratio:} Price-to-amount-seized ratio, acting as a proxy for market vulnerability.
              \item \textbf{Quality-Adjusted Price:} Normalizing price against purity levels to find true market cost.
              \item \textbf{Temporal Lag Variables:} Calculating year-over-year changes to observe the effect of seizures over time.
          \end{itemize}
\end{itemize}
